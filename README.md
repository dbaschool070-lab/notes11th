## 🚀 GitHub Pages से Publish करें

1. इस repo में सभी files upload करें
2. **Settings → Pages → Source: Deploy from a branch → main → /(root) → Save**
3. 1-2 मिनट में site live: `https://<username>.github.io/<repo-name>/`

## 🔍 SEO (Google में आने के लिए)

हर पेज में पहले से शामिल है:
- ✅ Title + Description + Keywords (हिंदी + English दोनों में)
- ✅ Open Graph tags (WhatsApp/Facebook पर सुंदर preview)
- ✅ JSON-LD Structured Data (Google के लिए)
- ✅ `sitemap.xml` और `robots.txt`
- ✅ Share image (`og-image.jpg` 1200×630)

**⚠️ ज़रूरी:** Upload करने से पहले सभी files में `YOUR-USERNAME` को अपने GitHub username से बदलें।

**Publish के बाद:** [Google Search Console](https://search.google.com/search-console) पर site add करें → `sitemap.xml` submit करें → कुछ दिनों में Google में दिखने लगेगी!
